## Overview
This repository contains all the MATLAB scripts, Simulink models, and LaTeX-generated PDF reports for the **MTR-311: Introduction to Mechatronics** lab assignments. 

The coursework focuses on simulating dynamic systems, modeling physical components, and applying control systems principles using MATLAB and its associated toolboxes.

## Repository Structure
The repository is organized into folders for each lab session. Each folder typically contains:
*   **`.m` files:** MATLAB scripts for mathematical calculations, data analysis, and plotting.
*   **`.slx` files:** Simulink block diagram models.
*   **`Report.pdf`:** The final submitted lab report detailing the problem statements, procedures, expected outputs, and results.
*   **`assets/`:** Any images, screenshots, or datasets required for the reports or codes.
